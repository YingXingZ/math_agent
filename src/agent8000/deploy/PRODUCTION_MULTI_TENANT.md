# 多教师正式部署清单

这份清单针对可被其他教师使用的部署，而不是当前的本机开发模式。

## 上线前必须完成

1. 准备 Linux 应用服务器、域名和 DNS A/AAAA 记录；8000、8014、18080 都只监听私网或 loopback。
2. 复制 `.env.production.example` 到服务器私有文件 `/etc/math-agent/math-agent.env`，填写唯一的管理员登录名和强密码；设置 `AUTH_REQUIRED=true`、`COOKIE_SECURE=true`。
3. 在首次启动时，环境变量会仅在没有管理员时创建一个管理员。管理员登录后，通过 `POST /api/admin/teachers` 创建教师；临时密码只通过安全渠道单独交付。
4. nginx 仅转发 8000；用 Certbot（`certbot --nginx -d your.domain`）签发证书并将 HTTP 重定向至 HTTPS。**8014 证据库与 18080 VLM 禁止公网映射。**
5. 启用 `math-agent-backup.timer`：`systemctl enable --now math-agent-backup.timer`。每季度执行一次恢复演练：在隔离目录恢复备份，启动副本，校验账号、班级、作业与抽样附件。

## 隔离与角色

- 管理员：创建教师、读取服务状态与审计日志；不以日常教师账号操作。
- 教师：仅能读取/修改本人 `teacher_user_id` 下的班级、名单、作业、学生提交、报表和个人题目。官方题库可读但对教师只读；其他教师私有题不可见。
- 学生：必须以教师生成的邀请码，且与导入名单的学号和姓名相符，才能激活账户；提交时账号必须与名单绑定。

## 数据与隐私规则（默认值，须由学校确认）

| 数据 | 默认保存 | 谁可访问 | 处理原则 |
|---|---:|---|---|
| 姓名、学号、班级 | 在班周期 + 1 年 | 本班教师、管理员（审计） | 仅用于身份、作业和成绩统计 |
| 作业原图/PDF | 365 天 | 本班教师、受审计管理员 | 不公开 URL；到期前导出/删除须教师确认 |
| 分数、复核证据 | 教学周期 + 学校规定 | 本班教师、管理员 | 不用作模型公开训练 |
| 登录与操作审计 | 730 天 | 管理员 | 用于安全追踪，不展示给其他教师 |

当前保留期是配置项，并不自动物理删除附件；上线前由学校明确制度后，再启用“预览 → 管理员确认”的清理任务，避免误删教学证据。

## 当前外部阻塞项

尚未提供域名、服务器、DNS 和学校的数据保留制度，因此本仓库只能交付可部署配置，不能声称已完成公网 HTTPS 上线。部署完成后请执行健康检查，并以真实教师/学生账号做一次隔离验收。
