# 试运行部署手册

这是单门课程或小规模试点的单机部署基础。Web 服务、截止检查与批改任务分为独立容器，数据库与学生提交文件存放在持久化卷。

## 部署前必做

1. 将 `.env.example` 复制为 `.env`，填写真实 Dify 地址和密钥；密钥只存于服务器。
2. 在具备 Docker Compose 的 Linux 服务器执行 `docker compose up -d --build`。
3. 通过学校已有网关配置 HTTPS，并接入统一认证或受控 VPN；不要直接暴露端口到公网。
4. 教师确认后才发布主观题成绩；手写推导默认进入复核状态。

## 数据治理

- `homework_data` 包含数据库和提交原件，应每日加密备份到学校合规存储。
- 正式扩大到多班级后，将 SQLite 迁移到 PostgreSQL、文件卷迁移到 MinIO/学校对象存储。
- 投产前必须落实统一认证、班级名单来源、HTTPS 域名、OCR/公式识别与 Dify 工作流密钥；这些依赖学校账户和合规策略，不能以本地假配置替代。
