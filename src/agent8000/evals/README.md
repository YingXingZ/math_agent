# 批改质量黄金验收集

运行：

```bash
python -m evals.run_grading_quality_eval
pytest -q
```

当前第一层覆盖六类结构化案例：正确、错误、空白、未完成、识别不确定、数学等价写法。

发布门槛：

- 误放行率（错误/空白/未完成被自动判对）必须为 0；
- 误复核率（明确正确或等价答案被送人工）必须为 0；
- 黄金集总体准确率必须为 100%。

新增批改规则时，必须先添加能复现问题的黄金案例，再修改实现。后续第二层将加入匿名化 PDF 题区图片，并分别统计视觉作答存在性、完整性、OCR 覆盖率和数学评分准确率。


## 教师确认反馈评测

在服务器项目根目录执行：

```bash
PYTHONPATH=src/agent8000 python -m evals.run_teacher_feedback_eval
```

工具只读 `grading_experiences` 中的模型候选分和教师确认分，按评分模型、作业和整份提交做稳定排序留出集，输出总体、模型、作业和题目级指标；不会打印学生姓名、作答原文或逐份提交分数。默认留出比例 20%，使用 `--seed` 固定切分；模型或规则改变后使用同一个 seed 重跑，比较同一留出集。小样本暂作方向性指标，不当作发布通过证明。

评分结果记录 `scoring_model` 和 `grading_prompt_version`。每次更改评分指令时递增提示词版本，避免将不同提示词的反馈混为一组。
