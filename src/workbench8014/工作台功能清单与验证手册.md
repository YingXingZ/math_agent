## 2. 验证与测试方法

> 通用前置：三个服务均在监听（见 §0）。使用 `curl` + 托管 Python 解析 JSON；Windows 路径用 Git-Bash `/d/...` 形式。

### 2.1 三层连通性（每次回归第一步）
```bash
curl -s -m 10 http://127.0.0.1:8014/api/health      # 期望 {"status":"ok",...}
curl -s -m 10 http://127.0.0.1:18080/health         # 期望 {"ok":true,"model_loaded":true,...}
curl -s -m 10 http://127.0.0.1:8000/                # 期望返回前端 HTML
curl -s -m 15 http://127.0.0.1:8000/api/agent/capabilities  # 期望 5 个 task，含 status
```

### 2.2 SQL 注入安全（已修复，固化复测）
- **方法**：对 `GET /api/problems` 的 `q / section_no / knowledge_pts / ptype` 各投放 `x') OR ('1'='1') --`。
- **预期**：返回合法 JSON、`total=0`、无 500、无全表泄露。
- **结果（本次已跑）**：四分支均 `OK total=0` ✅。
- **单元回归**：`python regression_where_clause.py`（覆盖 4 份源文件真实函数）→ 输出 `REGRESSION_TEST_PASS`。

### 2.3 教材同步（extract 工具）
```bash
curl -s -m 90 -X POST "http://127.0.0.1:8000/api/agent/sync-section?section_no=1.1" \
  | python -m json.tool
```
- **预期**：`source_total / synced_count / skipped_unreadable / ai_candidate_count / available_by_level{基础,提高,综合} / question_ids`。
- **判定**：`skipped_unreadable` 应为乱码题（被安全拦截，不进缓存）；`synced_count` 应为可读 OCR 题。
- **注意**：依赖 8014 该章节已有数据；当前 8014 空库会返回 `synced_count=0`（属预期，非 bug）。

### 2.4 组卷 + PDF（assemble 工具 / pipeline）
```bash
curl -s -m 90 -X POST http://127.0.0.1:8000/api/agent/pipeline/publish \
  -H "Content-Type: application/json" \
  -d '{"title":"测试作业","chapter":"1.1","class_name":"数学A班",
       "due_at":"2026-08-21T23:59:00","question_count":6,"basic_ratio":0.5,"advanced_ratio":0.35}' \
  | python -m json.tool
```
- **预期**：返回 `id`、选题 `questions`（含 `original_no` 原题号）、`actual_composition`、PDF 路径。
- **产物校验**：
  ```bash
  # 验证 PDF 有效（应为 %PDF 头，2 页）
  head -c 5 "D:/My File/大四/高数教材答案/高数作业助手/data/uploads/assignments/assignment_<id>.pdf"
  # 验证原题号写入库
  python -c "import sqlite3;c=sqlite3.connect('.../homework.db');print(c.execute('SELECT sort_order,original_no FROM assignment_questions WHERE assignment_id=<id> ORDER BY sort_order').fetchall())"
  ```
- **退化判定**：若某层可读题不足，应回落补足且**不空卷**；§1.1 真实数据仅 3 题且基础=0 → 退化为「2提高+1综合」属数据质量，非流水线 bug。

### 2.5 LaTeX 导出
```bash
curl -s -m 30 "http://127.0.0.1:8000/api/assignments/<id>/latex" | python -m json.tool
curl -s -m 30 "http://127.0.0.1:8000/api/assignments/<id>/latex.tex" -o out.tex  # 可编译 ctex 源码
```

### 2.6 提交 → 识别 → 批改 → 复核闭环
```bash
# 1) 学生提交（图片/PDF）
curl -s -m 60 -X POST "http://127.0.0.1:8000/api/assignments/<id>/submissions" \
  -F "student_no=S2026" -F "file=@/path/to/scan.jpg" | python -m json.tool
# 2) 到期批改（或 POST /api/grading/run-due）
curl -s -m 60 -X POST "http://127.0.0.1:8000/api/grading/run-due" | python -m json.tool
# 3) 查看初评证据
curl -s -m 30 "http://127.0.0.1:8000/api/submissions/<sid>/grading" | python -m json.tool
# 4) 教师确认成绩（低置信度必须走此步）
curl -s -m 30 -X POST "http://127.0.0.1:8000/api/submissions/<sid>/review" \
  -H "Content-Type: application/json" -d '{"score":85,"feedback":"..."}'
```
- **预期**：`grading_result.results[].recognized_work / math_equivalence.method / review_reasons`；`review` 后成绩与经验沉淀。
- **当前进度**：`submissions=1` 已有起点；`review_queue=0`（无待复核）。
