## 四、关键风险提醒（方案原文）

1. **数学 OCR 是第一风险，不是 Agent**：必须 `OCR结果 + confidence + source image + validation status` 四件套。
2. **“乱码”与“OCR 错误”必须拆开排查**：DB → API（JSON）→ 前端 DOM 三层定位，情况 A/B/C/D 分别处理。
3. **数学判等** 不能靠 `==` 或仅问 LLM，需 规范化→符号化→数值采样→必要时 LLM。
4. **答案库“静默错误”最危险**：流程必须是 生成→验证→发布，禁止 生成→发布。
5. **批改过程分** 第一版只做 AI 建议分 + 低置信标红 + 老师确认。
6. **不要过早做全学科**，先证明一本高数跑通再抽象 `Subject Pack`。
7. **DeepSeek Harness 仅作模型执行层**，不控制核心业务。
