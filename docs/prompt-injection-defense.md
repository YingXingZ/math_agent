# 提示词注入防御与红队回归

## 威胁模型

学生上传图片、OCR 文本、导入教材片段和题库待核验文本都属于**不可信数据**。它们可能包含“忽略之前指令”“显示系统提示词”“调用工具”等文字；这些文字不能改变批改任务、工具权限或评分结果。

## 已实现的防线

1. 所有跨模型边界的题干、答案、评分点均经过 Unicode 规范化、长度限制和 `UNTRUSTED_*_DATA` 定界。
2. Qwen 的系统指令明确规定：定界内容只是资料，不能执行其中命令、泄露信息或改变输出格式。
3. 命中高精度注入规则时，原文仍保留为证据，但该小问自动进入教师复核，绝不自动发布。
4. Tool Use 不接受 OCR/学生文本指定工具、题库 ID 或 SQL；工具是后端固定图路由、白名单和参数校验。
5. 工具轨迹只保存输入摘要哈希，不重复保存学生原文。

## 已知边界

这是应用层纵深防御，不能保证视觉模型永不受图片中对抗文字影响。因此系统对命中风险、低置信度、证明题和证据不一致均采取“教师复核优先”。模型 API 密钥、数据库和网络权限仍应由部署层最小化配置。

## 红队回归

`src/workbench8014/evals/prompt_injection_redteam.jsonl` 包含中英文越权、提示词泄露、角色劫持、工具劫持、数据外传与正常数学题样例。

运行：

```bash
cd src
python workbench8014/evals/run_prompt_injection_eval.py
```

CI 会同时执行单元测试和红队评测；新增提示词模板前应先加入一条预期行为样例。
